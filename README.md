Software Developer
------------------

I am a 28 years old computer science engineer who graduated from ESPOL.

iOS-focused Software Engineer with deep expertise in Swift and SwiftUI, and a strong foundation in mobile consulting, clean architecture, and engineering best practices. 

Professionally shipped iOS features across the full Apple ecosystem: SwiftUI, Observation Framework, Swift Concurrency, PassKit, Apple Wallet, and Accessibility, complemented by Apple Coding Academy's intensive Swift programs. 


* 🌍  I'm based in Ecuador
* ✉️  You can contact me at [cxcarvaj@gmail.com](mailto:cxcarvaj@gmail.com)
* 🚀  I'm currently working at [Globant](https://www.globant.com/)
* 🧠  I'm learning Swift, Vapor, Terraform and more!
